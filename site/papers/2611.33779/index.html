Card 03 核心贡献

核心贡献

  • 提出了一种用于无人机视频生成的双流条件框架，将帧对齐的摄像机指令与从首帧扭曲观测中导出的局部 SE(3) 几何线索相结合。
  • 引入了 6-DoF 变换感知预训练，通过先重建带有局部变换轴的 RGB 视频再进行标准 RGB 训练，建立对象外观与显式 6-DoF 变换轴之间的几何对应关系。
  • 在 Sekai 基准数据集上的实验表明，DuoWM 在视频质量、3D 一致性和轨迹跟随方面均显著优于现有方法。
Card 04 方法描述

方法描述

  • 基于 Wan2.2-Fun-5B-Control-Camera 扩散变换器构建，保留其原生文本交叉注意力和 Plücker-ray 摄像机适配器。
  • Action flow 将相机轨迹重采样并渲染为目标帧中的位置点和 RGB 方向轴标记，以对齐指令轨迹与目标帧。
  • Object flow 利用冻结的 MoSE3 模型估计深度和局部 SE(3) 变换，将首帧像素前向扭曲到目标视角，并叠加局部坐标轴和轨迹标记。
  • 采用 变换感知预训练，第一阶段使用叠加了局部变换轴的 RGB 帧作为重建目标，第二阶段切换为无标记的 RGB 视频进行训练。
  • 使用 Flow Matching 目标进行训练，通过扩展 Patch Projection 注入双流条件，并使用秩为 32 的 LoRA 进行参数高效微调。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：Sekai-game-drone（5,118 训练 / 474 测试视频）和 Sekai-real-drone（4,368 训练 / 402 测试视频）。
  • 模型规模：基础模型为 5B 参数，隐藏维度为 3072，微调时新增双流和掩码通道，总输入通道数为 197。
  • 训练资源：文中未明确提及具体 GPU 型号，但提到预编码文本和视频潜变量以移除编码器并降低 VRAM 使用，游戏域使用全局 batch size 16 和学习率 1e-4。
Card 06 评估与结果

评估与结果

  • 评估环境：在 Sekai-game-drone 和 Sekai-real-drone 测试集上进行评估，对比基线包括 Captain Safari、Wan2.2-5B base、CameraCtrl 等。
  • 主要指标：视频质量（FVD、LPIPS）、3D一致性（MEt3R）、轨迹跟随（AUC@30、AUC@15、CosSim）。
  • 关键结果：在真实域上，相比 SOTA 方法 Captain Safari，FVD 和 LPIPS 分别降低 17.2% 和 21.6%。
  • 在游戏域上，AUC@30 从 0.5003 提升至 0.5719，AUC@15 从 0.3088 提升至 0.3747，各项指标均取得最优。
