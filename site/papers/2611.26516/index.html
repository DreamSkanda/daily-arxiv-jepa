Card 03 核心贡献

核心贡献

  • 提出生成式可规划 4D 世界的新范式，联合生成未来 RGB 外观和完整 4D 几何（深度、相机射线、点云、场景流）
  • 提出 Plan4D 统一框架，包含场景流预测头和几何-视频拼接机制，将冻结的 3D 基础模型与预训练视频生成器连接，保留几何先验的同时实现动作条件下的动态 4D 未来预测
  • 通过冻结的拼接解码器作为可微几何评判器，使无标签动作视频能够同时监督视觉预测和物理 4D 一致性
  • 在场景流估计、3D 重建和动作条件视频预测等多个任务上达到 SOTA 性能
  • 验证了冻结的 DA3 token 已编码跨帧运动线索，支持轻量级运动读出而非完整运动建模
Card 04 方法描述

方法描述

  • 场景流头增强：在冻结的 Depth Anything 3 (DA3) 上添加轻量级 DPT 风格场景流头，预测每像素前向 3D 位移，通过旋转适配器将局部相机坐标系映射到统一参考帧
  • 潜在到几何的模型拼接：设计 3D 卷积拼接模块，将 Wan 2.1 VAE 视频潜在表示上采样后映射到 DA3 编码器某层通道维度；通过正则化线性拟合自动选择最优注入层
  • 拼接解码器微调：采用教师-学生蒸馏与真实标注监督的混合训练策略，教师为原始冻结 DA3（含场景流头），学生为拼接解码器
  • 联合视频与 4D 几何训练：将拼接解码器冻结后作为可微几何评判器，视频扩散模型使用潜在流匹配目标训练，几何损失直接作用于去噪后的潜在估计，实现单次前向推理同时输出 RGB 和 4D 几何
Card 05 数据集与资源

数据集与资源

  • 训练数据集包括 PointOdyssey、Dynamic Replica、Virtual KITTI 2、BlinkVision、OmniWorld-Game、ScanNet++、MVS-Synth、Action100M
  • 评估数据集包括 MOVi-F、Dynamic Replica、PointOdyssey、ETH3D、ScanNet++、Dynamic-RE10K、RobbySimVal、RLBench、HOIGen-1M、Epic-Kitchens-100
  • 基础模型为 LongCat-Video（使用 Wan 2.1 VAE，潜在通道数 C_z=16）和 Depth Anything 3
  • 训练资源：阶段1使用 16 张 H100 GPU（20 epochs），阶段2和阶段3使用 64 张 H20 GPU，每 GPU batch size 为 1
Card 06 评估与结果

评估与结果

  • 评估涵盖三个维度：动态 4D 几何（场景流）、拼接解码器几何保持能力、完整动作条件 4D 世界生成
  • 主要指标包括 EPE、APD₀.₀₅（场景流）、Acc./Comp./F-score（重建）、RRA@5°/AUC（相机）、δ₁/AbsRel（深度）、SC/Cap.Sim（视频质量）
  • 场景流评估中，Plan4D 在三个基准上使用最少训练数据（0.97M 帧）即取得最佳或接近最佳结果，如 MOVi-F 上 EPE 为 13.10、APD₀.₀₅ 为 93.32
  • 拼接解码器在 Dynamic-RE10K 相机估计上超越原始 DA3（AUC₃₀: 0.5350 vs 0.5333），在 Dynamic Replica 重建完整性上取得最佳（Comp.: 0.0658）
  • 联合 4D 生成在 HOIGen 上全面领先：视频质量 SC 为 0.9035、深度 AbsRel 为 0.1125、相机 RRA@5° 为 0.9809，显著优于 TesserAct、Gen3R 和 VIST3A 等基线方法
