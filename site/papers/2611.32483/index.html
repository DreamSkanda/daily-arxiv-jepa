CodeWAM: A Code World Action Model for End-to-End Autonomous Driving

2026-11-24 · 原文 · 翻译 · 2611.32483

提出了 CodeWAM，一种将可执行代码作为世界模型表示的自动驾驶世界模型，用于预测候选计划的执行后果。 通过代码模拟自车动力学（车辆状态演化），结合学习的视觉模型预测周围场景的后果，共同评估轨迹候选方案。 解决了自动驾驶规划中忽略车辆执行过程导致的高奖励但难以平滑执行的候选轨迹被错误选中，进而引起连续决策动作冲突的问题。

论文概述

Card 03 核心贡献

核心贡献

  • 提出了一种用于驾驶世界模型的自车动力学可执行表示，通过代码计算候选计划下的车辆运动。
  • 构建了 CodeWAM 框架，实现执行感知的连续规划，将前一计划的执行上下文与当前候选评估显式关联。
  • 在 NAVSIM 和 nuScenes 基准上进行了广泛的实证验证，证明了可执行自车模型无需额外训练即可改进多种规划器。
Card 04 方法描述

方法描述

  • 可执行程序：利用指定的控制器和车辆运动模型，基于当前状态和前一次计划信息，逐步推演候选轨迹产生的实际自车运动。
  • 学习场景模型：使用 DINOv2 适配 LoRA 编码多视角图像特征，通过 Transformer 解码器预测候选轨迹的场景后果（如碰撞风险、道路合规性）。
  • 联合决策：将代码推演的执行后果与视觉预测的场景后果结合进行轨迹评估，并使用校准阈值 $\lambda$ 限制过估候选的选取，将选定计划作为下一决策的上下文。
Card 05 数据集与资源

数据集与资源

  • 使用的数据集：NAVSIM (包含 v1 navtest, v2 navtest, NAVHARD) 和 nuScenes (用于零样本迁移测试)
  • 输入传感器：4 路相机 (4×C)
  • 模型后端：基于 DINOv2 与 LoRA 微调
Card 06 评估与结果

评估与结果

  • 评估基准：NAVSIM v1, NAVSIM v2, NAVHARD 及 nuScenes
  • 主要评估指标：PDMS, EPDMS 及其各项子指标（如 NC, DAC, EP, TTC, Comfort 等）
  • 关键实验结果：在 NAVSIM v1 navtest 上取得 93.6 PDMS，在 NAVSIM v2 navtest 上取得 92.1 EPDMS，在 NAVHARD 上取得 50.6 EPDMS
  • 零样本迁移至 nuScenes 及与 Hydra-MDP、DrivoR 等集成时，无需额外训练即可提升规划性能和连续决策执行一致性。
