DraftKV: Protecting Persistent Worlds through Hierarchical Streaming Retrieval

2026-11-24 · 原文 · 翻译 · 2611.31944

交互式视频世界模型在重访先前探索过的位置时，难以维持长期的空间几何和外观一致性，而保留所有历史 KV 缓存会带来巨大的存储和计算开销。 论文提出了 DraftKV，一个免训练框架，通过基于几何接地和查询条件相关性的分层检索策略来高效检索历史 KV 缓存。 结合 CPU 卸载与分块流式注意力机制，大幅减少 GPU 内存占用和推理延迟，从而在单卡 GPU 上实现高质量的长程交互式世界生成。

Card 03 核心贡献

核心贡献

  • 提出分层草稿检索机制，结合“草稿接地”进行空间一致的 KV 检索和“草稿细化”进行细粒度查询相关的 KV 选择，并提供了完整的理论分析证明其有效性。
  • 引入流式 CPU-to-GPU 注意力，通过分块流式传输重叠 H2D 数据传输和注意力计算，将 GPU 活跃 KV 内存限制在固定数量的块内，独立于检索历史长度。
  • 在多种自回归视频世界模型和长时序基准上进行了大量实验验证，证明了方法在生成质量、内存占用和推理速度上的显著优势。
Card 04 方法描述

方法描述

  • Draft Grounding (草稿接地)：使用相机几何（双边视锥重叠分数）识别空间上相关的历史 KV 帧，提供粗粒度的空间约束。
  • Draft Refinement (草稿细化)：在接地的候选帧内，利用低分辨率的草稿注意力分数进行块级别的细粒度查询相关 KV 选择，避免了全分辨率的历史扫描。
  • Streaming CPU-to-GPU Attention (SCG-Attention)：全分辨率历史 KV 存储在 CPU 内存中，仅在需要时按块流式传输到 GPU，利用 FlashAttention 的分块计算特性，重叠数据传输与计算，并循环复用固定的 GPU 缓冲区。

Card 06 评估与结果

评估与结果

  • 评估基准：VBench-Long 和 ORBIA 数据集，比较对象包括 ShadowKV, FreeKV, InfiniGen, InfLLM 等方法。
  • 主要评估指标：主观/背景一致性、运动/动态程度、美学质量、图像质量、闪烁程度、长程持久性、3D 一致性 以及端到端时间(E2E)、FPS、GPU 峰值内存。
  • 关键实验结果：相比其他 CPU 卸载的 KV 缓存检索方法，DraftKV 实现了 3.27× 的端到端加速和 42.2% 的峰值 GPU 内存减少；同时长程生成持久性提升了 13.7%，整体性能提升了 5.0%。
