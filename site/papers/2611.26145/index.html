Card 03 核心贡献

核心贡献

  • 首次提出农业世界建模任务，并发现现有图像生成模型无法将植物生长与预测时间窗口对齐、无法达到正确生长阶段、无法保持个体一致性
  • 提出AgroWM模型，包含推理模块PhenoClock和生成模块Rooted Renderer，实现"先推理再渲染"的生长预测范式，在水稻和玉米上均取得最优结果
  • 指出标准指标如PSNR和SSIM无法指导生成生态学意义的植物，并引入基于植物自身照片序列的身份、几何、颜色和时间四维评估体系
  • 提出Growth Script机制，通过"后见之明"方式从真实未来数据反向编写训练脚本，实现特权信息学习
  • 在长期预测（9-20周）中相比无脚本基线提升10.7个点的Stage R@1，证明推理对长期预测至关重要
Card 04 方法描述

方法描述

  • PhenoClock（推理模块）：基于Qwen3.8-27B视觉语言模型，使用LoRA微调，从当前照片推断当前生长阶段、预测未来阶段，并输出包含高度、面积、颜色等数值目标的Growth Script
  • Rooted Renderer（生成模块）：基于Qwen Image 2.1的7B扩散Transformer，以当前照片为编辑输入，按照Growth Script对照片进行编辑，添加新器官和颜色变化，保持植物身份和框架不变
  • Hindsight Tutor：使用GPT-6.1 Sol，从训练对的未来照片和记录数据反向编写参考脚本，数值来自记录和测量，语言模型只负责文字描述，并设有严格的泄漏控制和验证机制
  • 训练采用flow-matching目标函数，文本和VAE编码器保持冻结，在20,000个训练查询上训练2个epoch
Card 05 数据集与资源

数据集与资源

  • WGSR数据集：93个水稻品种的周度照片，含俯视和前视两种视角，8个生长阶段标注，20,000训练查询（252株）和2,000验证查询（79株）
  • WGSM数据集：224个玉米自交系的9个生长阶段照片，6,400训练查询（348株）和1,600验证查询（84株）
  • 两数据集均来自OPIA（Open Plant Image Archive）
  • 模型规模：PhenoClock基于Qwen3.8-27B，Rooted Renderer基于Qwen Image 2.1（7B），Hindsight Tutor为GPT-6.1 Sol
  • 模型和代码已开源：GitHub和HuggingFace
Card 06 评估与结果

评估与结果

  • 评估指标：DINO相似度、IoU、面积/高度/密度误差、黄棕色比例误差、Stage R@1、Event R@1，以及PSNR/SSIM（仅供参考）
  • 基线模型包括GPT Image 2/2.5、Qwen Image 2.1、FLUX.2 Klein、LANCE、Agricrafter等
  • 水稻主实验：AgroWM达到54.6% Stage R@1和24.8% Event R@1，显著优于GPT Image 2.5（34.8%/10.8%）和Qwen Image 2.1（24.0%/1.1%）
  • 长期预测（9-20周）：AgroWM达到46.4% Stage R@1，相比最强基线Qwen Image 2.1 FT的35.7%提升10.7个点
  • 玉米泛化实验：AgroWM达到30.9% Stage R@1，优于Qwen Image 2.1 FT（30.1%）和GPT Image 2（21.1%）
  • 消融实验：去除PhenoClock降低7.2个Stage R@1；去除Rooted Renderer降低至24.8% Stage R@1；使用Hindsight Tutor脚本（上界）达到58.9%
  • Growth Script准确率：当前阶段89.9%、未来阶段78.9%（±1阶段为99.4%），语义相似度0.842
