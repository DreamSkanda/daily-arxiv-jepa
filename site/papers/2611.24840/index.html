Card 02 论文概述

论文概述

  • 研究自动驾驶世界模型中动作条件语义预测（action-conditioned semantic forecasting）的动作依赖性问题，即模型预测是否真正使用了输入的动作信息
  • 现有评估仅关注预测保真度和下游规划性能，很少验证预测是否依赖于条件动作；由于驾驶数据中自车运动高度自相关，模型可能仅靠历史信息就获得高精度而忽略动作输入
  • 提出通过测试时动作干预（action interventions）直接衡量模型对动作的依赖程度，并在合成环境和真实数据上验证
Card 03 核心贡献

核心贡献

  • 提出统一的动作条件语义预测框架，在单一U-Net预测器中比较FiLM、输入级拼接和无动作三种条件变体
  • 开发测试时干预协议，将执行的未来动作替换为shuffled、zero-yaw、stop和mean动作，仅用标准分割指标衡量动作依赖
  • 在具有已知动作依赖动力学的合成驾驶环境中验证干预方法的有效性，并使用打乱动作训练的负对照模型
  • 在Cityscapes和BDD100K两个平台上进行跨平台评估，包括数据集内和跨平台迁移实验
Card 04 方法描述

方法描述

  • 使用U-Net架构（4个分辨率级别，64/128/256/512通道）将4帧上下文语义分割图映射为未来预测
  • 三种动作条件变体：FiLM（通过MLP将动作向量映射为特征调制参数）、Concat（将动作广播为常数平面与输入拼接）、No action（无动作输入）
  • 采用残差公式：输出logits = U-Net输出 + λ × onehot(S_t)，λ为可学习标量，使模型从copy-last基线出发仅学习变化量
  • 自回归滚动预测K=3步，训练目标为逐像素交叉熵；水平翻转增强同时翻转偏航率以保持物理一致性
Card 05 数据集与资源

数据集与资源

  • Cityscapes：2,975个训练片段，500个验证片段，分辨率1024×2048，使用车辆里程计获取速度和偏航率
  • BDD100K：1,528个多目标跟踪片段（从1,600个筛选），分辨率720×1280，速度来自GPS，偏航率由GPS航向时间导数计算
  • 使用SegFormer-B5（Cityscapes上82.2 mIoU）生成两个数据集的分割输入和目标
  • 模型参数量：FiLM 13.07M、Concat 12.56M、No action 12.55M
Card 06 评估与结果

评估与结果

  • 评估指标：mIoU（所有类别平均交并比）和MO-mIoU（可移动物体类别平均交并比），短期（0.18-0.2s）和中期（0.54-0.6s）预测
  • 在Cityscapes上，执行动作最多提升中期mIoU 2.5点；错误动作最多降低mIoU 23.2点，低于无动作模型
  • 在BDD100K上，执行动作最多提升中期mIoU 0.6点；错误动作最多降低mIoU 7.0点
  • 在真实数据上，FiLM条件比输入级条件对动作的依赖性强1.6倍（精度相似），但在合成环境中两者依赖程度相同
  • 结论：精度提升表明模型使用了动作，但不能反映预测对动作的依赖强度
