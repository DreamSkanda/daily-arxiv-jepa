Do We Still Need Reinforcement Learning When We Can Read the World Model?

2026-11-25 · 原文 · 翻译 · 2611.34656

本文提出了一种新范式，利用自主 LLM 编程智能体通过阅读可读世界模型（即环境源代码）直接合成可执行的控制策略，而无需任务特定的强化学习（RL）训练。 智能体将环境知识转化为决策规则，并利用在线执行反馈或离线数据集迭代优化策略代码。 论文旨在解决传统 RL 方法严重依赖交互数据的问题，探讨直接策略合成是否能替代试错学习。

Card 03 核心贡献

核心贡献

  • 提出直接从环境源代码（可读世界模型）合成控制策略的新范式，无需任务特定的 RL 训练即可生成有效决策程序。
  • 在多种在线和离线决策基准上进行了广泛实验，证明合成策略在性能上匹配或超越传统 RL 方法，同时大幅减少环境交互需求。
  • 深入分析了合成策略的可解释性及其通过反馈驱动的演化过程，揭示了环境知识如何转化为具体决策规则。
  • 对比了有无源代码访问的策略合成效果，并在稀疏奖励、部分可观测等挑战性条件下验证了该范式的鲁棒性和优势。
Card 04 方法描述

方法描述

  • 将环境源代码定义为可读世界模型，其中显式编码了状态转移动态和奖励机制。
  • 使用基于 LLM 的自主编程智能体（如 Codex）分析源代码，推导最大化长期回报的决策规则，并将其转化为可执行的控制程序。
  • 策略优化采用迭代细化机制：在在线设置中，通过执行候选策略收集轨迹反馈来修改代码；在离线设置中，通过比对固定数据集中的高/低回报轨迹来诊断和修正策略弱点。
  • 评估过程与策略开发严格分离，评估反馈不提供给智能体，评估交互不计入开发预算，确保比较的公平性。

数据集与资源

  • 在线基准数据集：SMAC、MPE、MiniGrid、Box2D
  • 离线基准数据集：D4RL（包括 Maze2D, AntMaze, Kitchen, MuJoCo, Adroit）、BabyAI
  • 使用的模型：Codex（由 gpt-6-astra 驱动，使用 max reasoning effort）
  • 训练资源：主要依赖大语言模型 API 推理，未提及传统 GPU/TPU 训练资源
Card 06 评估与结果

评估与结果

  • 评估环境涵盖 16 个在线任务（多智能体协调与单智能体控制）及多个离线任务。
  • 主要评估指标：回合回报和任务成功率。
  • 在线实验中，PS-RWM 在 16 个场景中的 15 个优于无模型 RL 基线（如 QMIX、MAPPO、DQN、PPO），在 MiniGrid 上达到 100% 成功率。
  • 离线实验中，PS-RWM 在 Maze2D、AntMaze、Kitchen 上取得最高平均归一化得分；在 BabyAI 上即使无示范数据也达到 100% 成功率。
  • 合成策略所需的环境交互经验远少于传统 RL（在线预算少于 1600 回合，离线甚至无需交互），但在 MuJoCo 连续控制任务上表现相对较弱。
