Assembly-JEPA: Using World Models for Fine-Grained Industrial Image Verification

Card 03 核心贡献

核心贡献

  • 首次将完整的 JEPA 世界模型（包含编码器和预测器）应用于工业装配验证任务，并在推理阶段保留预测器。
  • 针对细粒度视觉变化设计了三项关键架构改进：ROI 定位、逆向动作预测和最大池化。
  • 构建了全新的工业控制柜装配验证合成数据集和修改版的 CLEVR-Change 数据集。
  • 实现了无需显式负样本训练即可检测细粒度装配错误和动作-状态不匹配的自监督方法。
Card 04 方法描述

方法描述

  • 基于 LeWorldModel 架构，将原来的 ViT-Tiny 编码器替换为轻量级 ResNet18，并提取 Patch 级别的特征表示。
  • ROI 定位：通过计算装配前后 Patch 嵌入的差异图，找到变化最大的区域并裁剪出局部特征，解决装配位置空间不确定的问题。
  • 逆向动作预测：使用单一线性层从前后状态嵌入的差值中预测装配动作，强制编码器学习对动作敏感的潜在表示。
  • 最大池化：对目标 Patch 嵌入进行序列维度的最大池化聚合，减少未变化 Patch 对预测任务的干扰。
  • 结合动作条件预测损失、SIGReg 正则化损失和逆向动作预测损失进行联合优化。
Card 05 数据集与资源

数据集与资源

  • Control Cabinets Dataset：自建合成数据集，包含 10 个控制柜、7 种装配动作、162 个位置，共 16,200 对 512x512 像素图像对（20 个视角，5 种光照条件）。
  • Modified CLEVR-Change：基于公开数据集修改，固定相机视角，包含 20,000 对图像和 12 种状态变化动作。
  • 模型规模：编码器为 ResNet18，嵌入维度 D=64；预测器包含 8 个 Transformer 块和 16 个注意力头。
  • 训练配置：训练 50 个 epochs，使用 AdamW 优化器，学习率为 1×10^-4，Batch size 为 64（论文未明确提及具体 GPU 型号）。
Card 06 评估与结果

评估与结果

  • 评估基准：在自建装配数据集和修改版 CLEVR-Change 数据集上进行测试，并进行消融实验验证各组件贡献。
  • 主要指标：使用 AUROC（接收者操作特征曲线下面积）和 Precision-Recall 曲线评估，采用 Bootstrap 重采样估计置信区间。
  • 关键结果：原始 LeWorldModel 直接应用于装配任务仅获得 50.02% AUROC；完整的 Assembly-JEPA 在控制柜标准基准上达到 88.5% 验证 AUROC，并在测试集上达到 86.9% AUROC。
  • 鲁棒性评估：在更具挑战性的“Hard wrong-state”设定下，完整模型达到 81.3% AUROC；在 Modified CLEVR-Change 数据集上达到近乎完美的 99.5% AUROC。
