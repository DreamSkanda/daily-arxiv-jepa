Card 03 核心贡献

核心贡献

  • 提出 AlpaSafe 框架，复用冻结驾驶 VLA 生成候选时的最后一个 prompt-prefill 隐藏 token，无需额外 VLA 训练或推理时 rollout
  • 设计了风险感知选择器头部，预测每个候选的相对得分和碰撞/偏驶风险 logits，通过支配规则过滤高风险候选并选择最优轨迹
  • 实验证明 AlpaSafe 在所选 regret 和 top-1 一致性上优于 Alpamayo 默认规则和随机选择，将碰撞或偏驶率从 6.41%/6.10% 降至 4.93%
  • 通过匹配消融实验验证了场景信息的重要性，证明仅用最后一个 token 即可达到与使用全部 3086 个 token 相当的性能
  • 选择器仅 1.7M 参数，单次八候选决策耗时 0.75 ms，相比闭环仿真（约 891 秒）实现显著的效率提升
Card 04 方法描述

方法描述

  • 同一 Prefill 表示提取：通过捕获钩子记录冻结 VLA 在生成候选的同一前向传递中 prompt prefill 的最终层隐藏状态，使用 SHA-256 哈希确保位精确来源追踪，仅取最后一个 token h=H[-1]（4096维）
  • 轨迹编码器：3 层 pre-norm Transformer 编码器（4 头，宽度 128，前馈 256），将 64 个归一化航点编码为候选潜在表示
  • 场景读取器与融合：通过宽度 64 的瓶颈投影场景输入，使用单层交叉注意力块（6 头，残差连接）将场景信息融合到候选表示中
  • 输出与选择规则：预测有界相对得分 S·tanh(r̂/S) 和碰撞/偏驶 logits，移除在两个风险 logits 上被支配的候选，在剩余候选中选择得分最高者
  • 训练目标：七项加权损失（排名、居中、组均值、未来、进度、碰撞、偏驶），使用 AdamW 优化器，五折交叉验证
Card 05 数据集与资源

数据集与资源

  • 使用 AlpaSim 闭环驾驶模拟器，评估池包含 525 个场景、1575 个决策组、12600 个评分候选
  • 五折交叉验证：每折 357 训练场景、63 内验场景、105 测试场景；另有 122 场景开发集和 35 场景保留集
  • 冻结生成器为 Alpamayo-1.5（10B 参数），选择器头部为 1.7M 参数
  • 训练和评估在 NVIDIA RTX PRO 6000 GPU 上进行
Card 06 评估与结果

评估与结果

  • 评估环境：AlpaSim 闭环模拟器，525 个共享场景，每组 K=8 个候选
  • 主要指标：Selected regret（↓）、Top-1 agreement（↑）、Official score（↑）、碰撞率、偏驶率、任一事件率
  • LastToken（AlpaSafe）取得 regret 0.0512、top-1 0.348、score 0.5734，均优于默认（0.0611/0.239/0.5635）和随机（0.0586/0.238/0.5660）
  • 任一事件率降至 4.93%，相比默认 6.41% 和随机 6.10% 分别降低 1.48 和 1.16 个百分点
  • 消融显示场景盲输入（Null）事件率更高，全序列输入无显著性能提升但碰撞率更高
  • 部署成本：选择路径 0.75 ms/决策（GPU），而闭环仿真需约 891 秒（串行）或至少 111 秒（并行下限）
