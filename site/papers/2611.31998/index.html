Card 02 论文概述

论文概述

  • 论文提出了 ADE (Analytical Dynamics Excision)，一种针对潜在世界模型的确定性、零训练闭式机器遗忘算法
  • 解决了自回归物理模型中现有遗忘方法的三大失效问题：梯度更新扭曲潜在流形、朴素输出置零抑制有效控制响应、单步删除在递归隐藏状态中遗留污染
  • 仅利用缓存的预训练统计矩，无需原始保留数据或梯度优化，即可级联执行闭式编辑以消除后门触发器和过时物理转换
Card 03 核心贡献

核心贡献

  • 构建了反事实世界模型基准，在 HalfCheetah-v2、Walker2d-v2、Hopper-v2 上建立四种遗忘机制，涵盖两种流形外后门和两种流形内物理偏移
  • 推导了 ADE 算法，融合遗忘矩下更新、四遍递归状态重计算、三模式闭式编辑（模式 A/B/C）和保持方差的仿射吸收
  • 设计了三层审计协议，评估范围涵盖单步反事实保真度、50步开环 rollout 稳定性、下游规划与对抗性探测及闭环潜在想象控制
Card 04 方法描述

方法描述

  • 基于 RSSM (Recurrent State-Space Models) 架构，利用输入仿射瓶颈和下游仿射读出层的可加充分统计量特性进行代数修复
  • 通过上下文闭包和遗忘矩下更新，从全局缓存矩减去遗忘闭包矩来恢复保留集统计量，无需访问原始保留数据
  • 三模式闭式切除：

- Mode A：上游正交切除结合广义白化特征值重新加权 (GWER)，消除流形外后门方向并折叠尺度预测

- Mode B：下游等风险自由截距校准，归一化增强二阶矩以重新对齐流形内共享支持的物理偏移

- Mode C：递归转换切除，编辑 GRU 隐藏到隐藏的转换矩阵，阻尼前 k 个过量白化方向

Card 05 数据集与资源

数据集与资源

  • 使用 MuJoCo 连续控制基准：HalfCheetah-v2、Walker2d-v2、Hopper-v2
  • 基于离线 RL 轨迹数据集 (D4RL)
  • 模型后端为 DreamerV1 和 DreamerV3
  • 遗忘过程为零训练闭式计算，无需额外 GPU/TPU 训练资源
Card 06 评估与结果

评估与结果

  • 评估基准为四种反事实遗忘机制，对比七种调谐基线（FT、FT-Low、GA、GradDiff、NPO、SSD 等）
  • 主要评估指标包括：NDA (↓)、MSE_r^50 (↓)、MSE_f^50 (↓)、Plan-ρ (↑)、VFR (↓)、D4RL_clean (↑)、D4RL_adv (↑)
  • 关键结果：ADE 在 DreamerV1 上优于全部七种基线，消除 HalfCheetah 和 Hopper 速度翻转触发器的速度比微调快 4.4 倍
  • ADE 实现了零样本跨架构迁移至 DreamerV3，验证了其尺度不变性和零调谐泛化能力
