Card 02 论文概述

论文概述

  • 论文提出 ViTrust 框架，旨在解决可变形物理世界模型中观测数据如何影响物理参数识别的问题
  • 核心目标是学习3D观测信任度，即决定每个跟踪点在每一时刻对物理参数识别的相对影响程度
  • 针对现有方法仅依靠视觉可靠性或对有效观测等权重处理而导致未来预测不准确的问题，提出结合视觉与接触证据的自适应加权方案
Card 03 核心贡献

核心贡献

  • 提出 ViTrust 框架，通过正则化的共享前向重建目标，联合学习逐点、时变的观测权重和物理参数
  • 设计 视觉-接触信任适配器，结合逐点时空证据与物体间及手-物交互上下文，利用持久patch分配和循环时序模型保留局部交互历史
  • 在 22个真实世界交互序列 上显著提升未来预测性能，相比 PhysTwin 基线，场景平均未来 Chamfer 距离降低 5.65%，跟踪误差降低 6.47%，LPIPS 降低 4.51%
  • 通过消融实验验证了视觉证据、接触上下文、权重正则化和交互历史各自的作用
  • 展示了拟合的物理参数在新控制和跨对象迁移场景下的泛化能力
Card 04 方法描述

方法描述

  • 基于 PhysTwin 的 Spring-Mass 物理模拟器和 3D Gaussian Splatting 渲染表示，保留原有的物理参数化与拓扑
  • 逐点时空证据：使用冻结的 CoTracker3 进行2D追踪并提升为3D，结合深度一致性和冻结的 VideoMAE-Base 视觉特征构建六维点描述子
  • 视觉-接触信任适配器：通过最远点采样建立持久对象patch，使用接触图消息传递和 GRU 编码交互历史，生成patch级接触调整并广播至各点，与视觉分数融合预测观测权重
  • 单阶段联合优化：通过共享前向模拟，每帧同时提供物理参数和适配器参数的偏梯度，使用带正则化的加权几何与对应损失进行更新，正则项防止权重坍缩并保证时间一致性和有效样本支持
  • 未来预测阶段直接冻结物理参数，在给定控制输入下模拟，无需重新拟合
Card 05 数据集与资源

数据集与资源

  • 使用 22个真实世界交互序列 和 735个未来帧 进行评估
  • 使用预训练且冻结的 VideoMAE-Base 和 CoTracker3 模型提取特征
  • 物理模拟基于 Spring-Mass 系统，渲染基于 3D Gaussian Splatting
Card 06 评估与结果

评估与结果

  • 评估基准包括 Spring-Gaus、GS-Dynamics、PhysTwin、MatPhys 和 DeformMaster
  • 主要评估指标包括 Chamfer Distance (CD)、Tracking Error、IoU、PSNR、SSIM 和 LPIPS
  • 在相同模拟器和初始化条件下，ViTrust 在未来预测的 CD 上达到 12.37mm，跟踪误差 24.70mm，均优于所有基线
  • 消融实验表明，移除接触图信任、权重正则化或GRU时序模块均会导致性能下降，验证了各组件的必要性
  • 定性结果展示了跨对象物理迁移和新控制下的模拟生成能力
